# 📞 Vendor Auto-Caller Agent

AI-powered automated vendor communication using Amazon Connect + Bedrock.

## What It Does

Automates vendor phone calls for:
- **Placing Purchase Orders** - Auto-call when PO is generated
- **Following Up on Late Deliveries** - Track and chase overdue orders
- **Checking Stock Availability** - Verify inventory before ordering
- **Negotiating Bulk Pricing** - Request volume discounts

## Call Types

### 1. Place Order
**When**: PO is generated by Replenishment Planner
**Script Includes**:
- Introduction
- Order details (items, quantities, total)
- Delivery date needed
- Confirmation request
- Callback number

**Example**:
```
"Hi Sarah, this is HeartKart Inventory Manager. I'm placing a purchase 
order for 3 items totaling $1,250. We need delivery by November 25th. 
Can you confirm this order? You can reach me at 555-0100 if needed. 
Thank you!"
```

### 2. Follow Up Late Delivery
**When**: PO is overdue
**Script Includes**:
- PO reference number
- Days late
- Items affected
- Request for updated ETA
- Polite but firm tone

**Example**:
```
"Hi, this is HeartKart calling about PO-2025-001. Our expected delivery 
was 3 days ago. Can you provide an updated ETA for the Red Ornaments and 
Gold Garland? We need to update our customers. Thank you."
```

### 3. Check Availability
**When**: Before placing large order
**Script Includes**:
- Items needed
- Quantity
- Urgency level
- Lead time request
- Pricing inquiry

**Example**:
```
"Hi, we need 200 Silver Bells and White Wreaths urgently. Can you check 
stock availability? What's the lead time and pricing for this quantity? 
Thanks!"
```

### 4. Negotiate Pricing
**When**: Bulk order opportunity
**Script Includes**:
- Current pricing
- Proposed quantity
- Target price
- Volume discount request
- Relationship emphasis

**Example**:
```
"Hi, we've been ordering from you regularly. We're planning a bulk order 
of 500 units. Current price is $12.99 each. Can we discuss volume pricing 
around $10.50? We're flexible and value our partnership."
```

## Usage

### Python API

```python
from vendor_caller_agent import (
    call_vendor_for_po,
    follow_up_late_delivery,
    check_stock_availability,
    negotiate_bulk_pricing
)

# 1. Place Order (auto-triggered from Replenishment Planner)
po_data = {
    'vendor': 'Holiday Decor Wholesale',
    'po_number': 'PO-2025-001',
    'items': [
        {'name': 'Red Ornaments', 'quantity': 100},
        {'name': 'Gold Garland', 'quantity': 50}
    ],
    'total_cost': 1250.00,
    'expected_delivery': '2025-11-25'
}
result = call_vendor_for_po(po_data)

# 2. Follow Up Late Delivery
result = follow_up_late_delivery(
    po_number='PO-2025-001',
    vendor_name='Holiday Decor Wholesale',
    days_late=3,
    items=['Red Ornaments', 'Gold Garland']
)

# 3. Check Availability
result = check_stock_availability(
    vendor_name='Holiday Decor Wholesale',
    items=['Silver Bells', 'White Wreaths'],
    quantity=200,
    urgency='high'
)

# 4. Negotiate Pricing
result = negotiate_bulk_pricing(
    vendor_name='Holiday Decor Wholesale',
    items=['Heart String Lights'],
    quantity=500,
    current_price=12.99,
    target_price=10.50
)
```

### REST API

```bash

curl -X POST http://localhost:5000/api/vendor/call/place-order \
  -H "Content-Type: application/json" \
  -d '{
    "vendor": "Holiday Decor Wholesale",
    "po_data": {...}
  }'

# Follow up late delivery
curl -X POST http://localhost:5000/api/vendor/call/follow-up \
  -H "Content-Type: application/json" \
  -d '{
    "vendor": "Holiday Decor Wholesale",
    "po_number": "PO-2025-001",
    "days_late": 3
  }'

# Check availability
curl -X POST http://localhost:5000/api/vendor/call/check-availability \
  -H "Content-Type: application/json" \
  -d '{
    "vendor": "Holiday Decor Wholesale",
    "items": ["Silver Bells"],
    "quantity": 200
  }'

# Get call history
curl http://localhost:5000/api/vendor/calls?vendor=Holiday+Decor+Wholesale
```

## Amazon Connect Integration

### Setup Required:

1. **Create Amazon Connect Instance**
   ```bash
   aws connect create-instance \
     --identity-management-type CONNECT_MANAGED \
     --instance-alias heartkart-vendor-calls
   ```

2. **Configure Contact Flow**
   - Create outbound contact flow
   - Add Bedrock integration for AI responses
   - Configure call recording
   - Set up transcription

3. **Add Phone Number**
   - Claim phone number in Connect
   - Configure outbound calling
   - Set caller ID

4. **Enable Call Recording**
   - S3 bucket for recordings
   - Transcription with Amazon Transcribe
   - Sentiment analysis

### Production Flow:

```python
# In production, this would actually dial:
connect_client.start_outbound_voice_contact(
    DestinationPhoneNumber=phone_number,
    ContactFlowId='your-flow-id',
    InstanceId='your-instance-id',
    Attributes={
        'script': generated_script,
        'vendor_name': vendor_name,
        'call_type': call_type
    }
)
```

```python

    vendor = product['vendor_name']

        vendor_name=vendor,
        items=[product['name']],
        quantity=product['reorder_quantity'],
        urgency='critical'
    )
```

## Cost Estimate

### Amazon Connect Pricing:
- **Outbound calls**: $0.018/minute
- **Average call**: 2 minutes = $0.036
- **100 calls/month**: $3.60

### Amazon Bedrock (Nova Lite):
- **Script generation**: ~500 tokens
- **Cost per call**: $0.0001
- **100 calls/month**: $0.01

### Total: ~$3.61/month for 100 vendor calls

**ROI**: Saves 5-10 minutes per call = 8-16 hours/month saved!

## Limitations

- Requires Amazon Connect setup
- Business hours only (configurable)
- English language only (expandable)
- Vendor must answer (voicemail detection needed)
- Follow-up requires human review
